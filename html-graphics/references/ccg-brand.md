# CCG brand guide — when it applies

The official CCG brand guide (colours and fonts below) is for **official,
formal college-branded content only** — policy documents, official
communications, leadership-facing materials. Check with Brendan before
applying it to anything else (faculty banners, casual internal graphics,
etc.) rather than assuming it's wanted.

## Official fonts
Novel Pro (headings) and Sofia Pro (body/bold) per the brand guide — but
treat these as indicative rather than mandatory for HTML/PNG rendering:
they don't reliably load as web fonts in this container (see the font
gotcha in `references/gotchas.md`), so unless the font files are supplied
and embedded directly, **Segoe UI or Arial** is the practical substitute
for anything text-heavy, matching the same fallback approach used for
Word/PDF body text.

## Non-brand-locked work
For everyday internal graphics that aren't official college-branded
content — faculty banners, casual announcements, subject-specific
graphics — a freer, more playful palette is appropriate and often
preferable. School colours can still be used as an accent without being
brand-guide-compliant. Confirm which mode applies if it's unclear from the
request.
